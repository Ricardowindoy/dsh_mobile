dsh_mobile · Apple 三端

手机 App 连接页、桌面 App 窗口、DSH 设置页的「远程访问」分区。三处共用同一份令牌与同一套组件层：落地时各改排版，不改数值。

01

数值只有一个来源

浅色逐字节取自插件 styles/apple.css，深色逐值取自 palettes.json#apple-night。由 tools/gen-tokens.mjs 生成，任何人手抄都会漂移，包括我自己第一版。

02

深色是 palette，不是发挥

第一版曾自创深色（brand #0a84ff）。官方夜间档是 #3d9dff 配 brand-on:#041e33 才过 AA。规范把深色定为风格之外独立一层，本套已换回官方值。

03

密度是结构决定的

竖排字段（label 上 / input 下）每个字段吃掉 ≈76px，两个字段就占掉 390×844 屏的近三分之一；再加上「29px 大标题 + 副标题 + 17px 卡标题 + 13px 卡说明」四级堆叠，一屏只看得到一个表单框。这一版改成：字段同行（每字段一行）、标题固定 24px、说明并入组脚注、同类项合并成一行摘要 —— iOS 设置页的骨架。合并不是隐藏：unit 名与状态都在，只是收在默认收起的 <details> 里。

04

闸门会失败

每条规则都做过变异检验：注入裸色值、动尺寸属性、触屏命中区不足、未声明令牌、图形令牌当文字色，全部报红；合规项不误报。规则条数以 check.mjs 自己打印的为准 —— 文档里不写数字，写了就会漂。「写着规范」不等于「成立」。

页面索引

01 · 手机 App 连接页
三段式：材质顶栏 / inset-grouped 分组 / 贴底材质栏。字段同行（标签左、输入右），标题 24px，说明并入组脚注。含键盘弹起与错误态。0.1.19：扫码配对升为主路径（手输 token 降级救急分组），⑨ 画扫描中/陌生 host 确认/码失效三态。
390×844 · 320×568 · 390×400 · 触屏命中区 44px
02 · 桌面 App 窗口
同一页的宽屏形态：内容收到 560px 居中，不拉满表单；字段同样同行（桌面档行高 34px）。桌面没有相机插件，扫码分组按真实行为隐藏（不是漏画）。
1280×800 内切 420×760 与 900×700 · 命中区 28px
03 · 设置页「远程访问」分区
可交互原型：宿主外壳只画一次，7 个数据态由顶部的状态机切换（含入场动画、入口切换、刷新 busy）。状态值一律胶囊，刷新按钮在「状态」标题行右侧并与卡片右缘对齐；三个 unit 合并成一行摘要 + details 展开。0.1.19 新增「扫码配对手机」分区：P1–P4 四态（码活着/未生成/已过期/relay 未启用）+ 设备列表两步撤销。
桌面 1280（行 32px/控件 28px，宿主实测）+ 手机 390 移动档（导航横条/行 44px/评审折叠，宿主 767px 同式）· 现状是内联样式，落地改令牌
04 · 审批推送卡片
0.1.19 / WP4：手机原生通知三态（审批卡两 action / 提问卡无文本 / 已处理回执）+ 桌面说明分区。语义规则：有订阅才认领、沉默不是同意、先答先赢。
390 宽通知画布 · 浅/深并排 · action 命中区 44px · 落地是 Kotlin NotificationCompat（系统渲染为准）

令牌对照（浅色 → 深色 apple-night）

画布与文字
令牌浅 → 深
--set-bg#f5f5f7 → #0d0d0f
--set-surface#ffffff → #1c1c1e
--set-surface-2#fafafc → #26262a
--set-text#1d1d1f → #f5f5f7
--set-text-2#6e6e73 → #a1a1a6
--set-text-3#86868b → #6e6e73

--set-text-3 限定给 placeholder 与弱标注；成句说明一律 --set-text-2（小字要够 4.5:1）。

品牌与语义
令牌浅 → 深
--set-brand#0071e3 → #3d9dff
--set-brand-on#ffffff → #041e33
--set-ok#1a8f4a → #30d158
--set-warn#b25000 → #ffd60a
--set-danger#d70015 → #ff453a
--set-linergba(0,0,0,.08) → #3a3a3e

深色下主按钮文字是 #041e33（近黑）而不是白 —— 官方 palette 就是靠这个组合过 AA。材质条官方没给，由 --set-surface 同 RGB + .72 派生。

与第一版落地代码的差异

项已落地（自创）按规范应为
深色画布#000#0d0d0f
深色控件底#2c2c2e#26262a
深色 brand#0a84ff + 自造 #0060df#3d9dff + brand-on:#041e33
--set-text-3删除恢复，限定 placeholder
--set-warn删除（页面没落点）恢复：自检「设备离线」= 网络通、链路断

逐条改法与验证方式见 docs/落地清单.md 的 A1–A7。
