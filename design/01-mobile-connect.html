项真实代码现状这张稿子的做法为什么 / 怎么落地
扫码配对（0.1.19） #scan-pair 主按钮 + 组脚注；main.js 扫码态文案「扫描中…/配对中…」；陌生 host 原生 confirm；redeem 404 →「配对码已过期或已被使用，请在桌面刷新二维码」；非 Android Tauri 环境整段隐藏 ①–⑧ 每台设备都加了扫码主路径；⑨ 画扫描中 / 陌生 host / 码失效三态。陌生 host 那屏是语义示意（真实是系统 confirm，不是页面内 banner） 手输 token 降级为「手动连接（救急）」分组，id 契约不变；设备 token 全程不进 URL（redeem POST body + 一次性 ticket），稿子里不出现任何凭据字样。
深色数值 已落地：styles.css 的 @media (prefers-color-scheme: dark) 已换官方 palette apple-night：画布 #0d0d0f、控件底 #26262a、brand #3d9dff 且按钮文字 #041e33（不再用白字）、材质 rgba(28,28,30,.72)、line #3a3a3e；values-night/colors.xml 的 canvas 同步 #FF0D0D0F（原先 #FF000000 比页面黑一档，启动瞬间有接缝） 与 App 现在的代码逐值一致（落地清单 A1/A2/A5/A6 已执行并实测：浏览器双档对比违规 0） 深色是独立 palette，不是自由发挥。白字压 #3d9dff 不足 4.5:1，官方靠近黑文字过 AA，所以 --set-brand-on 必须一起换。
自检「设备离线」 tone 缺省 → 中性灰文字，只有文案里的 ⚠️ .dot--warn + data-tone="warn"（--set-warn） A4：网络通、链路断既不是成功也不是失败。颜色 + 文字一起表达，不只靠颜色。
--set-text-3 被删（当时认为小字过不了 AA） 不直接收录；placeholder 走派生档 --set-placeholder（浅 = 官方 text-3 原值 #86868b，深 = text-3/text-2 逐通道中点 #88888d，压 #26262a 4.27:1）；弱标注仍 --set-text-2 A3：官方 palette 恢复了它，但它本身压 surface-2 只有 2.97，够不到"提示文字 ≥3"的自设线，所以派生一档而不是直接用。
信息密度 竖排字段（label 在上、input 在下），每字段 = 标签行 + 输入行 + 6px 间距 ≈ 76px；两个字段就吃掉近 1/3 屏。页面上另有大标题 29px + 副标题 + 卡片标题 17px + 卡片说明 13px 四级文字堆叠。 字段改同行（.field-row：标签左、输入右，每字段 44px 一行）；大标题降到 24px；说明合并进分组脚注（.group-foot）一行 12px；表单不再包"浮起的卡片"，改 inset-grouped 分组（.group--fill）。 Apple 的设置页骨架就是同行 + 分组。竖排是"表单页"思维，设置页要的是"一屏能看完"。这一屏现在能同时看到：标题 + 分组 + 两个字段 + 主按钮 + 自检行（原来只有标题 + 一个卡片）。
类名 .btn-primary / .field input / .error / .btn-ghost .btn.btn--primary.btn--touch / .field__input / .banner.banner--bad / .icon-btn（结构类名照抄真实代码） 控件走 base.css 组件层，结构类保持原名为逐条对照；落地时两种命名都行，闸门只认令牌与几何。
id 唯一性 一页一屏，relay-url/access-token/connect/self-check/push-log/error/update 各一个 只有①号设备用真实 id，其余 8 屏用 data-contract="同名" 标记同一契约 这一页并排画 9 个设备框，HTML 里 id 必须唯一；契约名保持一致即可逐条比对。

焦点环 / spinner 轨道 --set-ring（brand .22 alpha）外圈 4px；--set-spinner-track（brand .2） 焦点环已按派生层 --set-ring 与 base.css .field__input:focus 写成同一式（内圈 1px brand + 外圈 4px ring）；spinner 轨道用 --set-line 真实代码另有 --set-ring / --set-spinner-track 两个自加键；本页不新增令牌，焦点用已声明的 --set-ring，spinner 轨道退回 --set-line（品牌感略弱于原稿的 brand .2）。.is-focused 只是把同一组声明显式画给评审看，落地仍走 :focus。
